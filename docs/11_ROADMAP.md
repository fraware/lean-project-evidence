# Roadmap

## Milestone 0 — Foundation

Executable schemas, models, contract validation, stable IDs, ledger, TPPR, CI.

## Milestone 1 — Deterministic evidence

Git classification, exact build execution, hard gates, packet rendering, risk policy.

## Milestone 2 — Review operation

Question routing, review records, Markdown reports, GitHub Check adapter.

## Milestone 3 — Lean-aware evidence

Declaration metadata, signatures, axioms, dependency graph, impact cone, placeholder and import analysis.

## Milestone 4 — Semantic evidence

Statement differences, examples, counterexamples, replacement tests, duplicate retrieval.

## Milestone 5 — Shadow pilot

One active repository, 30–50 candidates, three review conditions, TPPR instrumentation.

## Milestone 6 — Learned routing

Train only after sufficient utility-ledger data and held-out evaluation exist.

## Milestone 7 — Project-targeted synthesis

Generate data around unresolved obligations and require causal improvement in held-out TPPR.
