# Definition of done

A feature is complete when:

- behavior is specified;
- API and data contracts are stable;
- success and failure tests exist;
- logs and provenance are emitted;
- documentation is updated;
- security implications are addressed;
- errors are actionable;
- outputs are deterministic or nondeterminism is declared;
- the feature has a stated path to TPPR;
- no unrelated scope is introduced.
