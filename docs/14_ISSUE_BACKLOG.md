# Engineering backlog

The canonical backlog is `backlog/issues.csv`.

Import issues to GitHub with `scripts/github_launch.py import-issues` (dry-run by default). See `docs/16_REPOSITORY_LAUNCH.md` section 5.

## Critical path

```text
Foundation
  → deterministic evidence
  → review operation
  → Lean extraction
  → semantic evidence
  → shadow pilot
  → learned routing
  → project-targeted synthesis
```

Model training and synthesis are intentionally outside the early critical path.
